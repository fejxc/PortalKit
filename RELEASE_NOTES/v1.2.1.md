# PortalKit v1.2.1

自包含 macOS 菜单栏应用（Apple Silicon 原生，无需安装 Python）。

**安装**：解压后将 `PortalKit.app` 拖入「应用程序」，双击打开。首次打开若提示未公证：右键 → 打开（本地签名，个人构建）。

## 本版修复：认证成功后又被"踢下线"（互踢循环）

**问题**（浙理工校园网现场发现）：手动认证成功后，PortalKit 的周期巡检误把门户的登录页当成"还需要认证"，**再次提交凭据——把你刚建立的会话踢掉**（学校限制单设备登录）。表现为反复掉线、需要反复手动认证。

**根因**：带会话参数的门户登录页**无论认证与否都会被伺服**，它不能作为"需要认证"的证据；同时校园网网关会**白名单放行** gstatic 等连通性检测域名，导致探针误报"已在线"。

**修复**：

- **双锁防互踢**：① 门户发现探测不再触碰旧入口登录页；② 自动认证需要同时满足"物理探针未通过"且"距上次成功认证超过 10 分钟"（成功时刻已持久化记录）
- **门户在场否决**：探针通过后仍会询问门户——只有确实没有已知门户时才判定"无需登录"（否则白名单假在线会掩盖真实认证需求）
- **指纹前置校验**：已信任门户的证书/页面指纹与本轮观测不符时（同网段冒名响应），不信任该识别结果；无其他门户可匹配时明确提示"门户特征变化"
- **多候选门户发现**：连通性检测域名被放行时（204），自动改试非白名单 HTTP 站——网关对未认证设备的重定向携带新鲜会话参数，是白名单环境下唯一可靠的入口来源
- 「重新检查网络」现在执行完整流程（检查 + 按需认证），不再只看状态；门户识别提示改为用户友好中文

116 项自动化测试通过（新增防互踢、指纹校验、多候选发现回归）。已在浙理工校园网（ZstuStudentWeb，Clash TUN 开启）真实环境验证。
