# PortalKit v1.3.2

自包含 macOS 菜单栏应用（Apple Silicon 原生，无需安装 Python）。

**安装**：解压后将 `PortalKit.app` 拖入「应用程序」，双击打开。首次打开若提示未公证：右键 → 打开（本地签名，个人构建）。

**升级**：v1.3.0 起支持应用内更新——菜单栏横幅一键完成。

## 管理可信网络 · 交互逻辑优化

### 「编辑凭据」跨窗口保持上下文
此前从管理窗口点「编辑凭据」，凭据窗口总是停在列表第一项——管理的和编辑的不是同一条。现在**凭据窗口直接定位到你正在查看的那条记录**。

### 撤销信任：两条路径一次说清
撤销确认改为三选一：**撤销信任（保留凭据）** / **撤销并删除凭据** / 取消。此前"想连凭据一起删"必须自己再去凭据窗口操作一遍；现在一步完成，且确认框明确说明撤销后的行为（不再自动认证、下次进入需重新确认信任、可随时重加）。

### 切换自动认证后详情即时同步
修复：切换「此网络自动认证」开关后，详情区"自动认证: 开启/关闭"仍显示旧值。

### 空记录态明确禁用操作
无受信网络时，「撤销信任」「编辑凭据」按钮与自动认证开关**置灰禁用**——此前点击会静默无反应，禁用是明确的反馈。

### 旧记录的"页面指纹: 未固定"加解释
v1.2.x 建立的信任记录没有页面指纹，此前只显示"未固定"（像异常）。现在注明「旧版本建立；重新添加可信网络可更新」。
