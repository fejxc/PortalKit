# PortalKit v1.2.0

自包含 macOS 菜单栏应用（Apple Silicon 原生，无需安装 Python）。

**安装**：解压后将 `PortalKit.app` 拖入「应用程序」，双击打开。首次打开若提示未公证：右键 → 打开（本地签名，个人构建）。

## 新特性

### 卡死会话一键直达系统设置
遇到"门户会话疑似卡住"等需要操作的状态时，菜单新增**「打开 Wi-Fi 设置…」**，点击直达系统设置 Wi-Fi 面板——把"忽略此网络后重新加入"的最后一段路铺平（平时隐藏，只在需要你操作时出现）。

### 会话寿命学习
zjlib 门户不告知会话有效期。现在 PortalKit 会**从你的真实重登历史中学习**：每次自动重登与前一次成功的间隔被记为一次"会话寿命"观测（取最近 10 次的中位数），用于估计"会话预计有效至"，并在临近过期时自动加密检查——过期后第一时间重登，而不是等你撞上断网。观测越多越准；门户主动下发 keepalive 时（如 zstu）仍以门户为准。

### 网络管理显示"上次连接"
每个受信网络显示最近一次"认证成功且物理验证通过"的时间，以及学到的典型会话寿命（如有观测）。

### 诊断时间线"只看异常"
诊断窗口新增开关：勾选后时间线只保留需要操作、待验证、失败与系统睡眠唤醒——扫一眼就知道今天出没出过事。

### 配置导出 / 导入（不含凭据）
设置窗口新增两个按钮：把受信网络与设置导出为一个 JSON 文件，换新机时一键导入（Keychain 凭据出于安全考虑不导出，导入后重录一遍即可）。导出文件经脱敏检查，不含密码 / 令牌。

## 性能与修复

- **检测动画定时器按需启停**：修复 1.1.0 引入的动画定时器常驻空转（约 8 次/秒的持续 CPU 唤醒）——现在只在真正执行网络任务时运行
- 菜单文案与图标仅在变化时重绘，减少无谓刷新
