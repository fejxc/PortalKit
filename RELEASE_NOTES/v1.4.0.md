# PortalKit v1.4.0

自包含 macOS 菜单栏应用（Apple Silicon 原生，无需安装 Python）。

**安装**：解压后将 `PortalKit.app` 拖入「应用程序」，双击打开。首次打开若提示未公证：右键 → 打开（本地签名，个人构建）。

**升级**：菜单栏横幅一键完成（v1.3.0 起支持应用内更新）。

## 会话历史：回答"前几天到底掉没掉线"

- 新增**本地会话历史**（留存 90 天）：认证成功、认证失败（含门户拒绝原因）、疑似设备互踢、悬挂会话清理四类事件自动留存。此前只有调试日志，高频状态事件几天就被冲掉，回看不了上周。
- **诊断窗口**新增「近 7 天会话汇总」：每天一行——成功 / 失败（含原因细分）/ 互踢 / 清理次数，"扫一眼这周有没有出过事"。
- 「最近事件」时间线优先读取会话历史，跨天带日期标签；只看异常模式照常可用。
- 「导出脱敏诊断」现在**附带完整 90 天会话历史**，提 issue 时一份文件说清全部情况。
- CLI 新增 `portalkit history`：按天汇总 + 明细（`--days` / `--tail`）。
- 隐私：历史文件只存事件类型 / 结果码 / 适配器与目标主机，**从源头不收自由文本**，无需二次脱敏。

## 浙理工（zstu / ePortal 门户）：「强制刷新会话」生效

- zstu 此前没有经过验证的注销能力——会话卡死时只能"忽略 Wi-Fi 重新加入"。本版实现 ePortal 标准注销流程（`InterFace.do?method=logout`，userIndex 取自门户回带），并以**入口回到登录页**为注销生效的最终判据（与 zjlib 同一纪律），随后自动重新认证。
- 所有 ePortal 站点（含用户自定义 JSON 站点）自动获得该能力。
- ⚠ 如实标注：注销协议基于 ePortal 公开惯例实现，已通过模拟门户全流程测试；**浙理工现场验证待 A02 闭环**（当前现场卡在门户拒绝凭据，待核对密码）。

## 设备超限（auth_quota）指引增强

- 诊断建议更新：在其他设备注销之外，新增「若本机此前在此网络登录过，先试**强制刷新会话**清理本机残留会话」——单设备限制的学校里，本机悬挂会话正是超限的常见来源。

## 遥测透明化

- 设置窗口新增**「查看将随更新检查上报的数据…」**：把匿名统计开启后将发送的 JSON 原样展示（未开启则明确说明"不附带任何数据"）。opt-in 遥测配上一眼可见的上报内容，信任成本归零。
