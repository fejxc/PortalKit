# PortalKit v1.1.0

自包含 macOS 菜单栏应用（Apple Silicon 原生，无需安装 Python）。

**安装**：解压后将 `PortalKit.app` 拖入「应用程序」，双击打开。首次打开若提示未公证：右键 → 打开（本地签名，个人构建）。

## 新特性

### 崩溃自愈
应用若意外崩溃（SIGKILL / 异常退出），launchd 会在约 10 秒内自动拉起——菜单栏图标不再可能"无声消失"。正常退出（点「退出 PortalKit」）保持停止。已在真实环境验证：kill -9 后 14 秒内新进程恢复已联网。

### 本地使用统计
诊断窗口与 CLI 新增一行今日概况：**今日检查 N 次 · 自动认证 N 次（成功 X · 失败 Y）· 平均耗时 X.Xs**。纯本地计数，不上传任何数据，跨天自动重置。

### 通知点击直达首次引导
发现未信任门户的系统通知，**点击直接打开「添加 / 确认可信网络」引导窗口**（含门户证据预填），首次配置从"翻菜单"变成"点一下"。

### 界面工程升级（用户不可见但重要）
- 菜单栏宿主从 rumps 迁移到**原生 NSStatusItem/NSMenu/NSUserNotification**——移除了为 pyobjc 12 兼容打的库内部补丁，菜单、图标、通知行为完全受控
- 窗口表单新增布局辅助组件，凭据与设置窗口已迁移（后续窗口增量迁移）
- 运行时依赖进一步收敛：UI 层第三方依赖归零（仅 PyObjC 系统桥接）

## 测试

106 项自动化测试通过；崩溃自愈、菜单启动、统计记录均在真实环境验证。
