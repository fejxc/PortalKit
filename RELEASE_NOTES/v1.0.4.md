# PortalKit v1.0.4

自包含 macOS 菜单栏应用（Apple Silicon 原生，无需安装 Python）。

**安装**：解压后将 `PortalKit.app` 拖入「应用程序」，双击打开。首次打开若提示未公证：右键 → 打开（本版本为本地签名，个人构建）。

## 本版修复：自动认证不再弹出钥匙串授权框

**问题**：每次自动认证都会弹出 "PortalKit 想要使用钥匙串中的 PortalKit.zjlib.2.2.1.1" 授权框，即使点过「始终允许」也在下次构建后再次出现。

**根因**：应用此前使用 ad-hoc 签名——每次重新构建都会产生一个新的代码签名身份，Keychain 按身份记忆的「始终允许」授权随之全部失效。

**修复**：

- 构建改用**稳定的本地代码签名身份**（`PortalKit Local Signing`，自签证书、有效期 10 年），重建不再改变应用身份，「始终允许」一次永久生效
- 覆盖保存凭据（删除 + 重建条目）全程**零弹窗**：删除路径不再解密条目内容，绕开了 Keychain ACL 授权
- 新增 `scripts/make_codesign_cert.sh`：幂等创建本地签名证书（处理了 OpenSSL 3 与 macOS 钥匙串导入的 PKCS12 兼容问题）
- CI/Release 构建无本地证书时自动回退 ad-hoc，发布流程不受影响

**升级说明**：从旧版本升级后，**第一次**自动认证可能还会弹出一次授权框——点「始终允许」即可，此后（包括以后所有新版本）永久免弹。若想连这一次都省掉：菜单「录入 / 更新凭据…」重新保存一遍凭据即可。
