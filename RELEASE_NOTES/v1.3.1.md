# PortalKit v1.3.1

自包含 macOS 菜单栏应用（Apple Silicon 原生，无需安装 Python）。

**安装**：解压后将 `PortalKit.app` 拖入「应用程序」，双击打开。首次打开若提示未公证：右键 → 打开（本地签名，个人构建）。

**升级**：v1.3.0 起支持应用内更新——菜单栏出现「发现新版本 — 点击更新」横幅后一键完成；旧版自动备份，失败自动回滚。

## 界面修复（来自 v1.3.0 实机巡检）

### 会话有效期过期明示
诊断窗口的「会话预计有效至」此前即使已过去数天仍以现在时显示（学习值会随时间自然过期），让人误以为会话仍有效。现在**时间已过即显示「会话已于 MM-DD HH:MM 过期（学习值）；点『立即认证』刷新」**；有效期统一为本地短格式，不再出现原始 ISO 串。

### 指纹分组显示
证书 / 页面指纹（64 位十六进制）在管理窗口与引导窗口改为**每 16 位分组**显示——指纹核对是信任确认的核心动作，此前窄栏内的随意断行既难读也难逐段核对。

### 诊断时间线去重
兜底检查每 30~120 秒落一条状态事件，时间线曾被连续十几条一模一样的「已联网（无需登录）」刷屏。现在**连续相同事件折叠为一条并标注 ×N**，时间线只看变化。

### 凭据窗口账号打码
长账号（>8 位）在凭据窗口显示为掩码（保留前 2 后 4，如 `36••••••••••••1710`），防止旁人瞥屏；保存时未修改打码显示则自动还原真实账号，更换账号清空重输即可。保存成功弹窗同步打码。短账号（学号等）原样显示。

## 测试

180 项自动化测试通过（新增 8 项：过期标注、未来期短格式、坏 ISO 隐藏、指纹分组、账号掩码、打码还原、掩码字符防御、时间线合并）。

## 升级提示

从 v1.3.0 应用内更新替换后首次自动认证可能弹一次 Keychain 授权（CI 构建为 ad-hoc 签名；本机构建可用 `scripts/make_codesign_cert.sh` 的稳定身份消除）。
