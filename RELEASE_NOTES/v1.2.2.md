# PortalKit v1.2.2

自包含 macOS 菜单栏应用（Apple Silicon 原生，无需安装 Python）。

**安装**：解压后将 `PortalKit.app` 拖入「应用程序」，双击打开。首次打开若提示未公证：右键 → 打开（本地签名，个人构建）。

## 新特性与改进

### 菜单状态联动
菜单项按实际状态动态启用/禁用：任务执行中只有「取消当前任务」可用；空闲时「取消」自动置灰——不再有点了没反应的"死"菜单项。

### 同校多门户凭据复用
同一学校多个区域门户（如浙理工图书馆/教学区）各自独立配置，但**凭据一次录入、处处复用**：引导窗口识别到同校其他门户时自动预填已录账号与密码，确认即可，不必重复输入。

### 互踢保护升级：识别"被抢占"并转人工
学校单设备限制下，若近期刚认证成功又掉线（疑似被手机等其他设备抢占），PortalKit **不再自动重提交**——那会与你的其他设备无限互踢。改为明确提示：「疑似其他设备抢占了校园网(学校限单设备)。请在其他设备上断开校园网后点『立即认证』」。手动「立即认证」不受限，可主动夺取会话。超过 45 分钟的掉线仍走全自动重登（自然过期不受影响）。

### 新增故障排查文档(docs/faq.md)
沉淀真实环境踩坑：Clash 代理与门户共存、单设备互踢、Wi-Fi 私有地址（MAC 随机化）导致"设备未注册"、白名单假在线、浏览器打不开内网门户等——README 已加入口。
