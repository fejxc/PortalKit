# PortalKit v1.3.0

自包含 macOS 菜单栏应用（Apple Silicon 原生，无需安装 Python）。

**安装**：解压后将 `PortalKit.app` 拖入「应用程序」，双击打开。首次打开若提示未公证：右键 → 打开（本地签名，个人构建）。

**从旧版本升级**：v1.3.0 起支持应用内更新——菜单栏出现「发现新版本 — 点击更新」横幅后一键完成下载、校验与替换；也可在设置里关闭「自动检查新版本」。

## 新特性

### 认证失败可行动诊断
认证失败不再只报"认证失败"。按门户返回文案分类为具体失败码，每类给出明确的下一步动作：

- **账号受限**（欠费/停机/锁定/冻结）→ 提示到学校自助服务网站处理
- **设备数上限**（含"账号已在线"）→ 提示先在其他设备注销再认证
- **凭据错误** → 提示改过密码就更新凭据（菜单栏 → 录入 / 更新凭据…）

诊断窗口的每类错误码都附「建议」行；门户原话保留在证据里（已脱敏）。

### ePortal 站点配置：加校园 = 一份 JSON，免发版
ePortal 是国内高校最普遍的认证后台家族之一。新建 `~/Library/Application Support/PortalKit/eportal_sites.json` 即可接入同协议校园（格式见 `eportal_sites.py` 文档字符串）：

```json
[
  {"id": "xxu", "name": "某某大学",
   "entry_url": "http://10.20.30.40:8080/eportal/redirectortosuccess.jsp"}
]
```

`id` 一旦建立信任就不要再改；配置损坏/非法条目自动跳过，绝不阻断启动。

### 应用内自动更新
后台每 6 小时检查 GitHub Release（启动后约 90 秒首查；设置可关）。发现新版本时菜单出现横幅：一键完成下载 → codesign 完整性校验 → 原位替换（旧版自动备份到 `~/Library/Caches/PortalKit/update-backup/`）→ 点击重启。任何环节失败旧版都保持原位。开发态/非 bundle 环境自动回退网页手动安装。

### 可选匿名遥测（默认关闭）
设置里新增「随更新检查附带匿名聚合计数」（默认关）。开启后仅随更新检查请求附带当日聚合计数（检查次数、认证成功/失败数、最常见失败码）——无账号、无主机、无任何自由文本。可在「导出脱敏诊断」中查看同源数据。

## 改进

### 现场证据回放测试
新增 `tests/fixtures/` 回放机制：把现场事故（白名单假在线、会话卡死 404、账号锁定拒绝等）固化为声明式 JSON 用例，CI 每次重放。今后现场排障「导出脱敏诊断」的证据可直接转成永久回归用例。

### 移除遗留依赖
`ui` extra 中残留的 `rumps` 声明已删除（v1.1.0 起菜单栏已是原生 NSStatusItem 实现，零第三方 UI 依赖）。

## 测试

172 项自动化测试通过（新增：失败码分类 10 项、现场回放 5 项、ePortal 参数化与站点配置 12 项、更新下载/替换 12 项、遥测摘要与请求头 4 项、账号受限/设备上限引擎映射 2 项）。

## 升级提示

- 从 v1.2.x 升级：信任记录、凭据、设置全部保留，无需重新配置。
- 应用内更新替换后首次自动认证可能弹一次 Keychain 授权（CI 构建为 ad-hoc 签名，签名身份随版本变化；本机构建可用 `scripts/make_codesign_cert.sh` 的稳定身份消除）。
