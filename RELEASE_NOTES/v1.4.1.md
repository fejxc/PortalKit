# PortalKit v1.4.1

自包含 macOS 菜单栏应用（Apple Silicon 原生，无需安装 Python）。

**安装**：解压后将 `PortalKit.app` 拖入「应用程序」，双击打开。首次打开若提示未公证：右键 → 打开（本地签名，个人构建）。

## 修复：应用内更新在 /Applications 下永远失败

- **现象**：v1.3.0–v1.4.0 点「一键更新」→ 下载成功但弹「更新失败，旧版本保持原位」（2026-11-16 现场实测）。
- **根因**：安装的解压暂存目录建在系统临时目录，而 macOS 的 `/Applications`（系统卷组）与临时目录（数据卷）**天然位于不同卷**——v1.3.0 的"跨卷拒绝安装"保护把所有标准安装位置一律误判为不支持原位替换。测试环境（同卷临时目录）从未暴露。
- **修复**：暂存目录直接建在 `.app` 所在目录旁（同卷，原子替换），删除误杀分支；目标目录不可写时安全退出并回退手动安装。
- **注意**：本修复只对新版本生效——**从 v1.3.x/v1.4.0 升级到本版仍需手动安装一次**（下载下方 zip 覆盖，或 Releases 页面），此后的一键更新才真正可用。
