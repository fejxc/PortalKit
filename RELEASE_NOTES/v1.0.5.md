# PortalKit v1.0.5

自包含 macOS 菜单栏应用（Apple Silicon 原生，无需安装 Python）。

**安装**：解压后将 `PortalKit.app` 拖入「应用程序」，双击打开。首次打开若提示未公证：右键 → 打开（本地签名，个人构建）。

## 本版修复：门户异常时菜单提示被截断、中英文混杂

**问题**：门户会话异常（如"入口可达但登录页不可用"）时，菜单显示的提示是一段被拦腰截断的中英文混排长句，无法阅读。

**修复**：

- 提示文案分层：菜单只显示**一句简短中文**（如「门户会话疑似卡住：请忽略此 Wi-Fi 后重新加入，仍失败联系管理员」）；完整技术指引只出现在「诊断与日志」的详情与导出中
- 菜单文案超长时以省略号收尾，不再从中间硬截断
- 适配器契约新增 `recovery_hint` 字段：需要用户操作的提示由适配器显式给出短句，引擎不再从技术证据里猜测

## 测试

100 项自动化测试通过（新增提示分层与截断回归）。
